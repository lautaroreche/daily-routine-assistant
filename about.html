Features

Built around a real shift

I use it every working day, so every feature replaced something I used to do by hand.

Resets itself every morning

Daily tasks come back unticked, weekly ones appear only on their day, and the handover form returns to its defaults. Nobody has to set anything up before the shift.

Batch codes that can't go wrong

Julian date codes with a fixed supplier suffix, adjusted with − and +. Future dates are blocked, and codes never drop below the latest known batch.

To doStartedDone

Warnings before running out

Every product has a reorder point. The stock count turns yellow when it gets close and red below it, so the order list is visible at a glance.

Reports written for you

A guided form turns the shift into a WhatsApp message, with the process rules built in and required fields checked before anything is copied.

Photos that answer questions

Every sushi tray and packaging item has its photo and exact contents. New photos come straight from the phone's camera.

Made for one hand and a phone

Big tap targets, steppers instead of keyboards, and an icon on the home screen. It opens like an app and works on any phone with a browser.

Under the hood

No backend, nothing to maintain

A single static page that keeps the shift's data on the phone, with the fixed data kept private and the published file encrypted.

Build App + base data App logic merged with a private base file: tasks, items, minimum batch codes, photos and roster.
StatiCrypt AES-256 encryption The whole page is encrypted with a password. The repository only ever contains ciphertext.
GitHub Pages Static hosting Free, always on, and redeployed a minute after each commit. No server to keep awake.
Phone localStorage + IndexedDB Day-to-day data and photos stay on the device. Sessions last 10 hours.

One file

Plain HTML, CSS and JavaScript. Only extra: pdf.js, loaded when a PDF roster is uploaded.

Isolated sections

Each tab is its own module with scoped styles and state, so one can't break another.

Base data kept apart

A new base updates every phone and keeps what was added on the phone itself.

Private by design

Logging out forgets the password without touching the data.

traceability.jsBatch codes · simplified
// Julian date: day of the year, 001–366
const julian = (d = new Date()) =>
  Math.floor((d - new Date(d.getFullYear(), 0, 0)) / 864e5);

function setBatchDay(item, day) {
  const today = julian();
  // never in the future, never below the latest known batch
  item.day = Math.min(today, Math.max(item.minDay, day));
  return `${String(item.day).padStart(3, '0')}-${item.suffix}`;
}

handover.jsReport header · simplified
// 14:00 on weekdays, 14:30 on Saturdays
function reportHeader(now = new Date()) {
  const [h, m] = now.getDay() === 6 ? [14, 30] : [14, 0];
  const due = new Date(now).setHours(h, m, 0, 0);
  const time = `${h}:${String(m).padStart(2, '0')}`;

  // before the report time it goes out as an estimate
  return now < due
    ? `*ESTIMATED HANDOVER ${time}*`
    : `*HANDOVER ${time}*`;
}

On the phone

Installed in three taps

No app store and nothing to download. The app is a web page that behaves like an app once it's on the home screen.

  1. Open the link on the phone and enter the password. The session lasts 10 hours.
  2. In Chrome, open the ⋮ menu and tap Add to Home screen.
  3. Open it from the icon. It starts on To Do, ready for the day.
Where does the data live? On the phone itself, never on a server. When clearing the browser history, untick Cookies and site data to keep the app's data.
